# Gestionnaire de Stock - Stock Management Application

Application web moderne pour gérer votre matériel de chantier en temps réel.

## 🎯 Fonctionnalités

✅ **Gestion du Stock**
- Ajouter/retirer du matériel facilement
- Suivi en temps réel

✅ **Historique Détaillé**
- Voir qui a pris quoi et quand
- Traçabilité complète

✅ **Recherche & Filtres**
- Trouver rapidement un article
- Filtrer par catégorie, date, utilisateur

✅ **Interface Responsive**
- Fonctionne parfaitement sur téléphone
- Accès depuis n'importe quel appareil

## 🚀 Technologies Utilisées

- **Frontend**: React 18, Vite, Tailwind CSS
- **Backend**: Node.js, Express, PostgreSQL
- **Auth**: JWT
- **API**: REST API

## 📦 Installation

### Prérequis
- Node.js 16+
- PostgreSQL 12+

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

L'application sera accessible sur `http://localhost:5173`
